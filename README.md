# 🌷 Blooming Tulip

### A Simple CSS Animation Project

A beautiful tulip that blooms when you hover over it! 🌸 This project uses HTML and CSS to create a soft, pastel-themed garden with an animated flower.

## ✨ Features

* 🌷 **Blooming Animation:** The tulip petals open when you hover over the flower.
* 🎨 **Pastel Background:** A soft gradient creates a dreamy atmosphere.
* 🌿 **CSS Plant Design:** Includes a stem, leaves, petals, and soil.
* ♻️ **Start Again Button:** Reload the page to restart the animation.
* 💗 **Pure CSS Animation:** The flower animation is created using CSS keyframes and transitions.

## 🛠️ Technologies Used

* **HTML5:** Structures the webpage.
* **CSS3:** Creates the flower, background, and animations.
* **JavaScript:** Reloads the page using the restart button.

## 🎨 Design

The project uses a soft pastel color palette:

* Lavender 💜
* Baby Pink 🌸
* Peach 🍑
* Cream 🤍
* Natural Green 🌿

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Hover over the flower to watch it bloom!
5. Click **Start Again** to restart the experience.
